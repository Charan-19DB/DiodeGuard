DiodeGuard

AI-Based Detection of Cyber Threats in Unidirectional IP Traffic
Theme: Blockchain & Cybersecurity · Critical Infrastructure Protection

Executive Abstract

Hardware data diodes provide physical Layer-1 assurance that data cannot flow backwards into high-security network enclaves. However, eliminating return packets renders standard bidirectional security mechanisms (TCP handshake tracking, active probing, inline IPS) entirely inoperative.

DiodeGuard introduces a purpose-built AI threat detection architecture specifically optimized for unidirectional IP streams. Operating strictly within a passive, zero-egress enclave, DiodeGuard leverages forward-flow behavioral feature extraction, in-memory sliding-window state tracking, and six specialized machine learning models to detect volumetric DDoS, botnet C2 beaconing, DGA tunneling, encrypted malware, reconnaissance, and covert data exfiltration in real-time.

1. The Problem Statement & The Unidirectional Dilemma

1.1 What is a Hardware Data Diode?

A hardware data diode is a physical cybersecurity appliance that enforces strictly one-way information flow. It couples a transmit photodiode to an optical fiber receiver, with the transmit optical pin physically excised on the receiving enclave side. This guarantees, at the physical laws of optics, that no packet, electrical pulse, or signal can ever travel backwards across the diode boundary.

The Fundamental Cyber Dilemma in Data Diode Enclaves
Standard Network Intrusion Detection Systems (NIDS) like Snort, Suricata, and Zeek, as well as stateful firewalls and inline IPS engines, are architected on bidirectional conversational assumptions:
  • They verify TCP 3-way handshakes (SYN → SYN-ACK → ACK) before creating connection states.
  • They calculate bidirectional round-trip times (RTT), window sizes, and payload client-to-server ratios.
  • They use active probing, TCP resets (RST), and honeypots to verify adversary behaviors.
When deployed across a unidirectional tap, traditional tools see only forward packets. As a result, they either flood security teams with false "half-open connection" alerts or miss sophisticated stealth attacks entirely.

1.2 How DiodeGuard Overcomes the Unidirectional Constraint

DiodeGuard replaces bidirectional state dependency with four core engineering innovations:

  • Forward-Only Feature Extraction: Computes statistical metrics (Shannon entropy, packet-size variance, inter-arrival variance, protocol ratios) solely from unidirectional ingress packets.
  • Sliding-Window Temporal State (Redis): Maintains rolling 5-minute state across source IPs without requiring connection-teardown packets (FIN/RST).
  • Multi-Model AI Taxonomy: Deploys six tailored machine learning algorithms trained specifically on forward-flow telemetry.
  • Zero-Egress SOC Dashboard: Delivers instantaneous threat visualization, evidence inspection, and acknowledgement without initiating reverse network probes.

Redis Sliding-Window State Manager

In unidirectional networks, hosts cannot send TCP FIN or RST flags to mark flow completion. DiodeGuard implements an in-memory sliding-window state manager using Redis sorted sets (flows:<src_ip>). It tracks rolling 300-second flow counters, packet rates, unique destination port carding, and Shannon entropy dynamically with atomic pipelines.

Cryptographic Model Integrity (SHA-256)

To safeguard against adversarial model tampering in isolated enclaves, every serialized model (.joblib) has a companion _hash.txt file containing its SHA-256 digest. Upon startup, detector.py verifies the file bytes against the digest before loading the pipeline, halting startup if any tampering is detected.

5. How DiodeGuard is Useful (Value Proposition & Operational Impact)

1. 100% Zero-Egress Physical Safety

Guarantees zero packet emissions or optical transmissions back into the monitored network. Protects sensitive air-gapped networks from side-channel signaling or leakage.

2. Critical Infrastructure Protection (CNI)

Enables real-time intrusion monitoring for SCADA/ICS grids, nuclear facilities, defense command systems, and financial backbones without endangering operational control.

3. Explainable Threat Provenance

Every emitted alert includes top contributing feature weights, confidence metrics, and heuristic flags (e.g., HIGH_SYN_BURST), empowering SOC analysts to triage incidents immediately.

4. Encrypted Malware Detection

Identifies malware communicating over TLS 1.2/1.3 using JA3 fingerprint catalogs, SNI entropy, and packet size distributions without requiring payload decryption.

Operational Efficiency via Offline Simulation Mode
DiodeGuard features an integrated mock telemetry generator (VITE_USE_MOCK=true). This enables immediate analyst training, offline demonstrations, and red-team drills without needing live network access or infrastructure dependencies.
